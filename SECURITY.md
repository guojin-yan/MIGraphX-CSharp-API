# Security policy

This repository has an unpublished `0.9.0-rc.1` local-prerelease process, retains `0.0.0` as its default build version, and has no supported release. Report security issues privately to the repository owner through GitHub's private vulnerability reporting when enabled; otherwise open a minimal issue asking for a private contact channel without disclosing the vulnerability.

Never include credentials, cloud endpoints, private keys, tokens, certificate bodies, device identifiers, proprietary models, or unredacted logs in an issue. M0 contains no native loader or P/Invoke surface, but future native-boundary reports should identify the affected MIGraphX/ROCm version and managed commit without attaching untrusted binaries.
