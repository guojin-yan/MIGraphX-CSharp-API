# API reference

The core namespace is `JYPPX.ROCm.MIGraphXSharp`. It provides diagnostics, ONNX inference, owned native resources, shape snapshots, model cache, graph construction, TensorFlow options, quantization and experimental custom operations.

The optional `JYPPX.ROCm.MIGraphX.CSharp.API.HIP.Interop` namespace provides `MIGraphXHipExecution`, `MIGraphXHipAsyncRun` and `MIGraphXHipDeviceInput`.

Generated pages describe types and methods from the assemblies' Chinese and English XML documentation. To build the local reference site, run `eng/docs.ps1` from the source checkout. The site is written outside the repository to `../MIGraphXSharp.Workspace/artifacts/docs/`.

Start with the [managed object guide](../guides/managed-objects.md) for ownership and copying, and read [platform limitations](../compatibility/platforms.md) for pending runtime qualification.
