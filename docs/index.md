# MIGraphXSharp documentation

MIGraphXSharp `0.0.0` is an engineering and research baseline for a future .NET binding to the official AMD MIGraphX C API.

M0 provides reproducible managed builds, package audits, clean consumers, machine-readable upstream evidence, and documentation infrastructure. It provides no native bindings, ONNX execution, runtime package, asynchronous execution, or AMD GPU result.

Start with [Getting started](guides/getting-started.md), then review the [framework](compatibility/frameworks.md), [platform](compatibility/platforms.md), and [native input](design/m0-native-baseline.md) evidence.

中文摘要：当前版本只建立工程与研究基线，不包含可执行的 MIGraphX 绑定。所有未来 GPU 能力都必须引用本项目自身、绑定已推送 Git SHA 的 Radeon Cloud 证据。
