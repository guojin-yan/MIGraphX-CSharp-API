## 更新摘要

- 首次提供 AMD MIGraphX 的 C# 核心包及可选 HIP 适配包。
- 支持 ONNX 解析、GPU 编译、类型化张量、同步推理、动态输入与模型缓存。
- 提供 HIP 异步提交和设备输入，完成后可取得主机输出副本。
- 两个包覆盖 15 个目标框架，并包含中英文 XML API 注释。
- 提供 YOLO26 五任务与 PP-OCRv6 文本检测、识别完整案例。

## 详细变更

### 核心 API

`JYPPX.ROCm.MIGraphX.CSharp.API` 包含原生库加载诊断、显式资源所有权、形状快照与类型化输入、ONNX 文件/内存解析、编译目标与同步执行。支持多输入输出、动态维度覆盖、程序保存/加载、模型缓存、类型化算子属性及图构建。

提供 TensorFlow 解析、FP16/BF16/INT8/FP8 量化和实验性自定义算子回调接口，实际使用范围见[高级 API](../guides/advanced-apis.md)与[平台说明](../compatibility/platforms.md)。

### HIP 集成

`JYPPX.ROCm.MIGraphX.CSharp.API.HIP.Interop` 提供 HIP 流提交、完成查询、同步等待及受管理的设备输入。精确依赖核心包 `0.0.1` 和 HipSharp `0.10.0`。主机输入和设备输入路径完成后均取得独立的主机输出副本；显存输出接续处理在 0.0.2 中提供。

### 示例与文档

- `Yolo26`：目标检测、图像分类、实例分割、姿态估计、旋转框检测，覆盖六个示例模型。
- `PaddleOcrV6`：tiny/small/medium 文本检测与识别，以及仅识别模式。
- 两个案例各自包含完整代码，无公共示例项目依赖，目标框架为 .NET 10。
- 提供 EXIF 方向处理、JSON/PNG/SVG 输出、张量导出、预热与重复计时。
- 该版本案例使用 C# CPU 数值前后处理和 MIGraphX GPU 推理，静态尺寸、batch=1、float32。
- 安装、资源管理、动态尺寸、HIP 集成与 API 参考随源码及离线 HTML 文档提供。

## 兼容性与弃用项

- 首次发布，无上一正式版本需要迁移，无弃用 API。
- 核心 C# 命名空间为 `JYPPX.ROCm.MIGraphXSharp`，与 NuGet 包名不同。
- HipSharp `0.9.1` 缺少适配器需要的内部流租约接口，不能替代 `0.10.0`。
- NuGet 包仅包含托管程序集，AMD 原生库由使用者另行安装。

## 安装方法

```bash
dotnet add package JYPPX.ROCm.MIGraphX.CSharp.API --version 0.0.1
# 需要 HIP 集成时安装：
dotnet add package JYPPX.ROCm.MIGraphX.CSharp.API.HIP.Interop --version 0.0.1
```

首次安装请阅读[入门指南](../guides/getting-started.md)与[运行环境部署](../guides/runtime-deployment.md)。也可从本版本 GitHub Release 下载包，作为本地 NuGet 源使用。

## 支持平台

| 组件 | 平台与版本 |
| --- | --- |
| 托管类库 | .NET Framework 4.6–4.8.1、.NET Core 3.1、.NET 5–10，共 15 个目标框架 |
| 已验证原生环境 | Ubuntu 24.04 x86-64、ROCm 7.2.1、MIGraphX 2.15.0、gfx1100 |
| 视觉案例 | .NET 10，使用者另行提供 ONNX 模型、图片与 OCR 字典 |

Windows/macOS 托管编译不表示提供相应的 MIGraphX 原生推理运行时。其他 GPU、原生版本与新模型需在对应部署环境评估。

## 已知限制

- 上述 MIGraphX 2.15.0 环境中的姿态模型需设置 `MIGRAPHX_DISABLE_REDUCE_FUSION=1`。
- OCR 使用矩形 unclip，不等同于 Paddle 的完整多边形 offset；不包含页面方向分类、去畸变、表格或版面分析。
- 通用 C 格式化可变参数与缺少原生销毁契约的独立 `migraphx_module_create` owner 不在公开封装范围；使用类型化属性与 program 所属 module。
- 实验性 custom-op 的 GPU/device 回调内存及完整 provider 生命周期尚未全面验证；不保证任意工作负载的零复制或流间并行重叠。
- 案例不含模型训练、视频跟踪与摄像头服务。完整边界见[平台说明](../compatibility/platforms.md)。

## 验证范围

发布覆盖托管构建与包消费检查、官方运行时功能运行，以及六个 YOLO26 模型、三种 OCR 规格和仅识别场景的真实 GPU 运行与独立 CPU 张量对照。该范围不扩展为所有模型、设备、原生版本或实验性回调的支持承诺。

## English Summary

- Initial release of the managed core and optional HIP adapter, both at version 0.0.1.
- Covers ONNX parsing/compilation, typed tensors, dynamic inputs, persistence/cache and graph APIs across 15 target frameworks.
- The HIP adapter requires core 0.0.1 and HipSharp 0.10.0, and returns host output copies after completion.
- Two self-contained .NET 10 samples cover YOLO26 five tasks and PP-OCRv6 detection/recognition with CPU preprocessing/postprocessing.
- Validated native baseline: Ubuntu 24.04 x86-64, ROCm 7.2.1, MIGraphX 2.15.0 and gfx1100. Install native libraries separately.
