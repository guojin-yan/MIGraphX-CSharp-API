# 0.9.0-rc.6 local prerelease candidate

This unpublished M11 candidate adds no public API. Core remains `27 types / 160 members`, adapter remains `3 / 11`, and the aggregate C API map remains `84 supported / 107 planned / 1 unsupported`.

It preserves the immutable rc.5 source, package identities, and failed official diagnostic record. The official session passed registry and explicit-lifecycle checks, then timed out in the first `m4-file-buffer-reference` iteration. The native worker did not respond to TERM, and the runner lacked a KILL escalation; no rc.5 case is promoted from that partial execution.

The rc.6 runner retains the 1,800-second session and 120-second case thresholds while adding a fixed, process-group-wide 10-second TERM-to-KILL escalation. The file/buffer case now flushes structured JSONL markers around file and buffer parse, shape, compile, argument/map creation, run, readback, content comparison, and resource teardown. The runner also stops invoking GPU runtime inventory utilities; GPU identity collection is a separate bounded preflight.

The candidate remains `runtime-deferred`. A new official execution requires the final pushed source SHA, exact core/adapter/HipSharp package hashes, a clean replacement host, and a bounded time window. No long-run, timing, publication, tag, release, Pages deployment, Actions run, or NuGet publication is authorized.
