# 0.9.0-rc.5 local prerelease candidate

This unpublished M11 candidate adds no public API. Core remains `27 types / 160 members`, adapter remains `3 / 11`, and the aggregate C API map remains `84 supported / 107 planned / 1 unsupported`.

It preserves the immutable rc.4 diagnostic record and corrects the project-generated dynamic Identity fixture. The single ONNX node and the single output ValueInfo are now retained as complete protobuf byte arrays instead of being expanded into individual bytes by PowerShell. The fixture still declares `[1,4]`; static and dynamic shape behavior remains exercised through the managed ONNX options API.

The candidate remains `runtime-deferred` until exact source/package identities, an official host, and a bounded time window are recorded for rc.5. The rc.4 M4/M6 successes and M5 fixture failure are diagnostic only and do not promote rc.5 runtime evidence. Long-run, timing, and Windows native policy remain separate M11 decisions.

It remains managed-only and unpublished; no tag, release, Pages deployment, Actions run, or NuGet publication is authorized.
