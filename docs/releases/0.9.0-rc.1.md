# 0.9.0-rc.1 local prerelease candidate

This unpublished candidate establishes a versioned compatibility baseline for the managed core and optional HIP adapter. It introduces schema 2 API snapshots, source-bound assembly identity, exact adapter dependencies, local-feed source mapping, product managed-package SBOM/provenance, and M8 prerelease gates. The baseline can be intentionally updated as interface coverage expands during the `0.x.x` line.

The managed packages remain native-free. The declared native baseline remains Ubuntu 24.04 amd64, ROCm 7.2.1, and MIGraphX `2.15.0.70201-81~24.04`, installed through AMD's official system repository. Runtime NuGet remains `not-applicable`.

Historical official evidence covers only M1/M2 on one recorded gfx1100 environment. M4 objects, M5 dynamic/Save/Load/cache, and M6 host/device async remain local fake-native evidence. Each new interface batch needs a fresh, exact cloud test record before it can be described as `runtime-executed`.

This prerelease candidate is not `release-ready` or published. Development remains on `0.x.x`. Final `1.0.0` requires completed Windows runtime validation plus an explicit owner instruction and is not authorized by this document.

中文摘要：`0.9.0-rc.1` 建立可随 `0.x.x` 接口扩展而审查更新的 managed API 基线，并补齐本地证据链；它不分发原生库，也不把历史 M1/M2 结果扩张到其他接口。Windows 实机验证和 Owner 明确授权之前不得进入或发布 `1.0.0`。
