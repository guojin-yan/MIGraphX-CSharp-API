The first copies the loaded native version's ONNX parser registry with strict UTF-8 and no borrowed pointer escape. The adapter uses exact `[0.9.0-rc.2]` core and `[0.9.1]` HipSharp dependencies. Package ZIP/content hashes, isolated consumers, manifest, CycloneDX SBOM, local unsigned provenance, and vulnerability scan are regenerated for the final pushed source SHA.
