# 0.9.0-rc.4 local prerelease candidate

This unpublished candidate adds no public API. Core remains `27 types / 160 members`, adapter remains `3 / 11`, and the fixed aggregate C API map remains `84 supported / 107 planned / 1 unsupported`.

It supersedes the failed `0.9.0-rc.3` M11 runtime attempt without mutating that historical candidate. The M5 probe fixture now declares a concrete `[1,4]` input and applies static or dynamic overrides through the managed options API, because the fixed official parser rejected the prior symbolic-dimension fixture. The M6 adapter now passes the ROCm 7.2.1 C ABI spelling `ihipStream_t` after the official runtime rejected the prior `hipStream_t` string.

The candidate remains `runtime-deferred` until a fresh Owner authorization binds its final source SHA, package hashes, official host, and bounded time window. The previous failed attempt is diagnostic evidence only, not a promotion of any M4-M6 runtime case. Long-run and timing remain separately authorized layers, and the fixed-version Windows provider remains `not-applicable`.

It remains managed-only and unpublished; no tag, release, Pages deployment, Actions run, or NuGet publication is authorized.
