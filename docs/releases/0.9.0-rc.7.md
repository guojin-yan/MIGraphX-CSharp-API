# 0.9.0-rc.7 local prerelease candidate

This unpublished M11 candidate adds no public API. Core remains `27 types / 160 members`, adapter remains `3 / 11`, and the aggregate C API map remains `84 supported / 107 planned / 1 unsupported`.

It preserves the immutable rc.6 source, package identities, and official functional record. That session restored and built the exact packages without warnings or errors, executed all 20 attempted cases, passed 18, and failed `m5-dynamic-overrides` plus `m5-invalid-range-name-shape`. The managed native-shape snapshot called `migraphx_shape_lengths` before checking `migraphx_shape_dynamic`; MIGraphX 2.15.0 rejected `lens()` on a dynamic shape with status 4. Cache restart and independent promotion review were correctly blocked, so no rc.6 case is promoted.

Rc.7 queries the native type and dynamic flag first. A dynamic shape reads only its native dynamic dimensions; lengths, strides, elements, bytes, and standard-layout state are read only on the static branch. Fake-native rejects those static-only accessors for dynamic shapes, and a dedicated regression test prevents the official-runtime ordering constraint from being hidden again.

The candidate remains `runtime-deferred`. A new official execution requires the final pushed source SHA, exact core/adapter/HipSharp package hashes, a clean host, and a bounded time window. No long-run, timing, publication, tag, release, Pages deployment, Actions run, or NuGet publication is authorized.
