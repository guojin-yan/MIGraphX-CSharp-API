# 0.0.0 engineering candidate

This unpublished local candidate includes M1 lifecycle work, M2's restricted ONNX workflow, M3's internal low-level binding pipeline, and M4's resource-safe synchronous object layer. M4 adds nine public types and maps the fixed 192-item low-level inventory to 52 supported, 139 planned, and one unsupported high-level item. The single C-variadic function remains explicitly unsupported.

It includes no AMD native binary, fake binary, PDB, model binary, or runtime package. Dynamic shapes, save/load/cache, asynchronous execution, streams, and device buffers remain excluded. M4 adds local static and fake-native evidence only. Official M1/M2 runtime validation passed at `f1a11cfd1701a041cee29188f7600c85b34ae260` for the recorded Ubuntu 24.04 / ROCm 7.2.1 / MIGraphX / gfx1100 environment and the generated static float32 Identity workflow; that older result does not validate M4 objects.
