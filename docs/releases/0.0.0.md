# 0.0.0 engineering candidate

This unpublished local candidate includes M1 lifecycle work plus M2's restricted ONNX workflow: 41 cumulative manifest-derived declarations, strict UTF-8, loader/frontend diagnostics, SafeHandle ownership, file/buffer parse, static float32 shapes, offload-copy compile, synchronous run, and copied output.

It includes no AMD native binary, fake binary, PDB, model binary, or runtime package. Dynamic shapes, a general shape/argument object API, asynchronous execution, streams, and device buffers remain excluded. Official M1/M2 runtime and AMD GPU validation are deferred until an authorized unified session records real loader, lifecycle, ONNX parse/compile/run, and reference results against a pushed commit.
