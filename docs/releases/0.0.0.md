# 0.0.0 engineering candidate

This unpublished local candidate includes M1 lifecycle work plus M2's restricted ONNX workflow: 41 cumulative manifest-derived declarations, strict UTF-8, loader/frontend diagnostics, SafeHandle ownership, file/buffer parse, static float32 shapes, offload-copy compile, synchronous run, and copied output.

It includes no AMD native binary, fake binary, PDB, model binary, or runtime package. Dynamic shapes, a general shape/argument object API, asynchronous execution, streams, and device buffers remain excluded. Official M1/M2 runtime validation passed at `f1a11cfd1701a041cee29188f7600c85b34ae260` for the recorded Ubuntu 24.04 / ROCm 7.2.1 / MIGraphX / gfx1100 environment and the generated static float32 Identity workflow.
