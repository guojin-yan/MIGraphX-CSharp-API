# 0.0.0 engineering candidate

This unpublished local candidate now includes M1 Direct P/Invoke work: manifest-derived target/program create, assign, and destroy declarations; strict UTF-8; status exceptions; native loader/export diagnostics; internal SafeHandle ownership; fake-native tests; ABI/export gates; and representative old/modern TFM execution.

It includes no AMD native binary, fake binary, PDB, model, runtime package, ONNX parse/compile/run, shape/argument API, asynchronous execution, or GPU inference. Official M1 runtime validation remains blocked until an authorized Radeon Cloud session records the frozen installation header, loader/export results, and target/program lifecycle against a pushed commit.
