# 0.0.0 engineering candidate

This unpublished local candidate includes M1 lifecycle work, M2's restricted ONNX workflow, M3's internal low-level binding pipeline, M4's resource-safe synchronous object layer, M5 dynamic shapes/Save/Load/cache, the optional M6 HipSharp async adapter, and M7 fail-closed Runtime supply-chain metadata. The M6 mapping remains 75 supported, 116 planned, and one unsupported high-level item over the fixed 192-item inventory. M7 adds no public API.

It includes no AMD native binary, fake binary, PDB, model binary, cache payload, or Runtime package. M7 records a signed Ubuntu Noble source lock, MIGraphX root ELF inventory, layered-deferred topology, CycloneDX SBOM, provenance, and loader marker guard. Provider closure/licenses, the size decision, clean Runtime consumer, and newly authorized package-only execution remain incomplete, so the status is `runtime-deferred` and all pack/publish/release flags remain false. Official M1/M2 runtime validation at `f1a11cfd1701a041cee29188f7600c85b34ae260` remains the only real-runtime evidence and does not validate M4-M7 or provide a zero-copy/performance claim.
