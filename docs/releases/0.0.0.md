# 0.0.0 engineering candidate

This unpublished local candidate includes M1 lifecycle work, M2's restricted ONNX workflow, and M3's internal low-level binding pipeline. M3 classifies 159 functions, 2 enums, 25 opaque handles, and 6 callbacks, then emits matching 158-EntryPoint `LibraryImport` and `DllImport` paths from one normalized model. The single C-variadic function is explicitly unsupported.

It includes no AMD native binary, fake binary, PDB, model binary, or runtime package. Dynamic shapes, a general shape/argument object API, asynchronous execution, streams, and device buffers remain excluded. M3 adds static and fake-native evidence only. Official M1/M2 runtime validation passed at `f1a11cfd1701a041cee29188f7600c85b34ae260` for the recorded Ubuntu 24.04 / ROCm 7.2.1 / MIGraphX / gfx1100 environment and the generated static float32 Identity workflow.
