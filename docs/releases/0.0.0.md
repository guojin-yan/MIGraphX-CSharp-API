# 0.0.0 engineering candidate

This unpublished local candidate includes M1 lifecycle work, M2's restricted ONNX workflow, M3's internal low-level binding pipeline, M4's resource-safe synchronous object layer, and M5 dynamic shapes, Save/Load, and explicit-root model cache. The M5 mapping records 74 supported, 117 planned, and one unsupported high-level item over the fixed 192-item inventory. The single C-variadic function remains explicitly unsupported.

It includes no AMD native binary, fake binary, PDB, model binary, cache payload, or runtime package. Async execution, streams, and device buffers remain excluded. M5 dynamic/save-load/cache evidence is local static and fake-native only. Official M1/M2 runtime validation passed at `f1a11cfd1701a041cee29188f7600c85b34ae260` for the recorded Ubuntu 24.04 / ROCm 7.2.1 / MIGraphX / gfx1100 environment and the generated static float32 Identity workflow; that older result does not validate M4 or M5 objects.
