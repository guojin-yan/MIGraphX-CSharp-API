# Radeon Cloud scripts

These credential-free scripts require `/workspace/MIGraphX-CSharp-API` to be a clean detached checkout of a pushed 40-character SHA. They do not connect to Radeon Cloud, install floating tool versions, disable TLS, package native files, or persist connection details.

The unified cloud test verifies the frozen installed header, official C library export subset, strict non-ASCII UTF-8 target name, target/program lifecycle, deterministic Identity model, file/buffer ONNX parse, static shapes, GPU-target compile, synchronous run, and reference output. The prepared M9 option path additionally calls the public Loop, external-data, fast-math, and exhaustive-tune settings before an Identity inference. It then packs the exact 0.0.0 managed package, generates the reviewed M12 fixtures, runs all thirteen implemented M12 candidate paths in one `--include-deferred` bounded session, and invokes the independent M12 reviewer. Identity demonstrates setter acceptance and regression only; it does not exercise Loop or external-data semantics, exhaustive tuning enabled, representative accuracy, async, streams, device buffers, multiple inputs/outputs, or performance.

Run `env-report.sh`, `bootstrap.sh`, prepare a clean sibling HIP-CSharp-API checkout when M6 source checks are required, then `COMMIT_SHA=<sha> cloud-test.sh` only after the Owner explicitly authorizes the current cloud session. `bootstrap.sh` fails fast unless git, .NET, PowerShell, CMake, and GCC are available, and restores the pinned DocFX tool using the selected NuGet cache. `cloud-test.sh` automatically passes `/workspace/HIP-CSharp-API/HIP-CSharp-API` through `HIPSHARP_REPOSITORY_ROOT` when that checkout exists; callers may set the variable to another exact source root. The M12 raw candidate record defaults to `/workspace/migraphx-cloud-records/<sha>/m12-candidate`, outside the source and package feed; `MIGRAPHX_CLOUD_RECORD_ROOT` may select another absolute isolated root. The script labels raw M2/M9/M12 output as runtime candidates; only reviewed, redacted evidence may promote any case to `runtime-executed`. Preserve and redact both `test-results` and the external M12 record under the outer Radeon Cloud record policy.
